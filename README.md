# JVM Case Study: Java and Kotlin

This repository contains a practical study on the interoperability between Java and Kotlin within the JVM ecosystem, developed for the Topics in Programming course at the Federal Technological University of Paraná (UTFPR).

## Repository Structure

- `example/`: Low-level demonstration compiling Java and Kotlin files to `.class`.
- `demo/`: Practical application demonstrating language integration in a functional scenario.

# Estudo de Caso JVM: Java e Kotlin

Este repositório contém um estudo prático sobre a interoperabilidade entre Java e Kotlin no ecossistema JVM, desenvolvido para a disciplina de Tópicos em Programação na Universidade Tecnológica Federal do Paraná (UTFPR).

## Estrutura do Repositório

- `example/`: Demonstração de baixo nível compilando arquivos Java e Kotlin  para arquivos `.class`.
- `demo/`: Aplicação prática cobrindo a integração das linguagens em um cenário funcional.
