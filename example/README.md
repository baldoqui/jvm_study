# Compilation Example

This directory demonstrates compilation and execution of Java and Kotlin files using command-line tools (`javac`, `kotlinc`, and `java`).

## File Description

- `ClassJava.java`: Class written in Java encapsulating internal string state and a display method.
- `MainKotlin.kt`: Application entry point written in Kotlin that directly instantiates `ClassJava` and invokes its methods.
- `build/`: Output directory containing compiled artifacts:
  - `build/ClassJava.class`: Bytecode generated by the Java compiler (`javac`).
  - `build/MainKotlinKt.class`: Bytecode generated by the Kotlin compiler (`kotlinc`).
  - `build/kotlin-stdlib.jar`: Kotlin standard library required for JVM execution.
- `META-INF/main.kotlin_module`: Metadata file generated by `kotlinc` containing module type and property specifications.

## Compilation and Execution Commands

To compile and execute this example on any POSIX environment with JDK and Kotlin installed:

```bash
# 1. Compile the Java class
javac -d build ClassJava.java

# 2. Compile the Kotlin file
kotlinc MainKotlin.kt -cp build -d build

# 3. Copy the Kotlin standard library to the build directory
cp /usr/share/kotlin/lib/kotlin-stdlib.jar build/

# 4. Execute the application using the JVM
java -cp build:build/kotlin-stdlib.jar MainKotlinKt

# Exemplo de Compilação

Segue a demonstração de compilação e execução de arquivos Java e Kotlin utilizando apenas as ferramentas de linha de comando (`javac`, `kotlinc` e `java`).

## Descrição dos Arquivos

- `ClassJava.java`: Classe escrita em Java que encapsula um estado interno de texto (`String`) e um método de exibição.
- `MainKotlin.kt`: Ponto de entrada da aplicação escrito em Kotlin que instancia diretamente a classe `ClassJava` e executa seus métodos.
- `build/`: Diretório de saída contendo os artefatos compilados:
  - `build/ClassJava.class`: Bytecode gerado pelo compilador Java (`javac`).
  - `build/MainKotlinKt.class`: Bytecode gerado pelo compilador Kotlin (`kotlinc`).
  - `build/kotlin-stdlib.jar`: Biblioteca padrão do Kotlin necessária para a execução do bytecode Kotlin pela JVM.
- `META-INF/main.kotlin_module`: Arquivo de metadados gerado pelo `kotlinc` contendo informações de tipos e propriedades do módulo Kotlin.

## Comandos de Compilação e Execução

Para compilar e rodar este exemplo em qualquer ambiente POSIX com JDK e Kotlin instalados:

```bash
# 1. Compilar a classe Java
javac -d build ClassJava.java

# 2. Compilar o arquivo Kotlin
kotlinc MainKotlin.kt -cp build -d build

# 3. Copiar a biblioteca padrão do Kotlin para o diretório de build
cp /usr/share/kotlin/lib/kotlin-stdlib.jar build/

# 4. Executar a aplicação via JVM
java -cp build:build/kotlin-stdlib.jar MainKotlinKt
